# Домашнее задание к работе 2

## Условие задачи
Поезд за m минут проходит t столбов. Определите скорость поезда, если между столбами S метров.

## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Задать исходные данные:
   - `m` = 7 (минут) — время за которое поезд проезжает t столбов.
   - `t` = 90 — количество столбов.
   - `S` = 5 (метров) — расстояние между каждым столбом.
3. Вычислить скорость поезда:
   - `V` = (`S` * `t`) / `m`
4. Вывести результаты расчета.
5. **Конец**

### Блок-схема
 (https://github.com/Avebanger/Lab02/blob/master/Диаграмма_lab02.png)


## 2. Реализация программы
```
#include <stdio.h>
#include <locale.h>
// Задача: Поезд за m минут проходит t столбов. Определите скорость поезда, если между столбами S метров
int main()
{
	setlocale(LC_CTYPE,"RUS");
	float m=7, t=90, S=5;
	float V = (S * t) / m;
	printf("Поезд проходит %1.0f столбов, расстояние между которыми %1.0f метров, за %1.0f минут.\n",t,S,m);
	printf("Скорость поезда: %1.2f", V);
}
```
## 3. Результаты работы программы

Поезд проходит 90 столбов, расстояние между которыми 5 метров, за 7 минут.	

Скорость поезда: 64.29
